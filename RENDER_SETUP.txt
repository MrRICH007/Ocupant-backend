OCUPANT UPDATED RELEASE
=======================

1. Keep the server file named exactly:
   Server.js

2. Render Start Command:
   npm start

3. DATABASE PERSISTENCE (IMPORTANT)
   The app still uses SQLite. Render's normal service filesystem is ephemeral.
   If you do not attach persistent storage, houses/users/payments can disappear
   after a restart or redeploy.

   Attach a Render persistent disk and mount it at:
   /data

   Then set this environment variable:
   DB_FILE=/data/ocupant.db

   The backend also automatically prefers /data/ocupant.db when it detects a
   Render environment with /data available.

4. Other required environment variables:
   JWT_SECRET=your-long-random-secret
   ADMIN_EMAIL=your-admin-email
   ADMIN_PASSWORD=your-admin-password
   FLUTTERWAVE_SECRET_KEY=your-flutterwave-secret
   FLUTTERWAVE_WEBHOOK_HASH=your-webhook-hash
   FRONTEND_URL=https://your-frontend-domain
   BACKEND_URL=https://your-backend-domain

   Optional payment settings now default to:
   PREMIUM_PRICE=10000
   PAYMENT_CURRENCY=NGN

5. MAPS
   Admin can paste a Google Maps link. The backend attempts to resolve shared
   Google Maps links and stores a browser-friendly embed URL when coordinates
   can be detected. Premium users get the precise map and an external Maps
   button as fallback.

6. VIDEOS
   Admin video field accepts direct video URLs, one per line. Videos are stored
   in SQLite as JSON and returned by the house API.

IMPORTANT:
If your current Render plan does not provide persistent disks, SQLite cannot
reliably retain production data across service replacement/redeploys. In that
case the long-term solution is moving the database to a persistent PostgreSQL
provider rather than keeping SQLite.
